## Day summaries

**Day 01 — Python Foundations**
Mutability & aliasing, the four core containers (list/tuple/dict/set), functions with keyword defaults, the five essential idioms (f-strings, comprehensions, lambda, try/except, with-open), and a hand-built salary-vs-skills analyzer. Homework: formatted skills table, JD keyword counter, and a `--title`/JSON extension to `jobs_tool.py`.

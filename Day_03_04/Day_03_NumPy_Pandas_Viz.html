The story

Why an image is a table too

A 28×28 grayscale digit is a NumPy array of shape (28, 28): 784 numbers between 0 and 255. A colour photo is (height, width, 3). A batch of 64 photos is (64, 224, 224, 3). A sentence, after tokenising, is a row of integers. A month of UPI transactions is a DataFrame with a million rows. Everything a model ever sees is an n-dimensional array, and NumPy is the language of arrays. PyTorch tensors, TensorFlow tensors, JAX arrays: all NumPy's children, with the same indexing, the same broadcasting rules, the same .shape.

The order today mirrors a real job: load with Pandas, compute with NumPy, look with Matplotlib, share with Git.

1. NumPy: think in shapes, not loops

🍬

The sweet-box analogy

A box of 12 laddoos in 3 rows of 4 is an array of shape (3, 4). "Add 5 g of sugar to every laddoo" is box + 5: one instruction, all 12 laddoos, no loop; the scalar is broadcast. "Add a different topping to each of the 4 columns" is box + toppings where toppings has shape (4,): NumPy stretches the 4 toppings across the 3 rows. "Give each of the 3 rows its own syrup" needs shape (3, 1), a column, so the stretch happens sideways. Try to add 3 syrups written as a row of shape (3,) to a (3, 4) box and NumPy refuses: the trailing dimensions (4 vs 3) do not match. That refusal is the most common NumPy error you will meet, and the visual below makes the rule visible.

Common confusion

Array views versus copies. Slicing a NumPy array (b = a[:, 0]) returns a view: same memory, so writing into b changes a. This is Day 01's sticker problem again, at the level of memory buffers. Boolean/fancy indexing (a[a > 0], a[[0, 2]]) returns a copy. When in doubt: .copy(). Pandas has the same issue, which is what the SettingWithCopyWarning is about; pandas 3.0 solves it with Copy-on-Write, so df2 = df[df.age > 30] is now always safe to modify.

2. Pandas: split, apply, combine

🏏

The IPL points-table analogy

The scorer has one long log of every match: (team, runs, result). To make the points table she splits the log by team, applies "count wins, sum runs" to each pile, and combines the piles into one table with one row per team. That is df.groupby("team").agg(wins=("won", "sum"), runs=("runs", "sum")). Every dashboard, every "average salary by city", every "churn rate by plan" is this one move. Watch it happen below.

The result of one line, df.groupby(["class", "sex"])["survived"].mean(), on the real data: 96.8% of first-class women survived; 13.5% of third-class men did. That single chart is the whole story of "women and children first" plus the location of the lifeboats. It took one groupby and one sns.barplot. On Day 06 a logistic-regression model will rediscover these same two features on its own.

Key idea

Exploratory data analysis (EDA) is asking "group by what?" and "plot what against what?" until the story appears. The libraries make each question one line, so you can ask fifty questions in an hour.

3. Matplotlib: figure, axes, then plot

The two lines to memorise: fig, ax = plt.subplots(figsize=(8, 4)) then ax.plot(x, y) (or ax.hist, ax.scatter, ax.bar). Everything else is labelling: ax.set(title=..., xlabel=..., ylabel=...). Seaborn wraps this so that sns.histplot(df, x="age", hue="survived") gives you a coloured, legended histogram in one call. Pandas even has a shortcut: df["age"].hist(). Use Seaborn for exploration, Matplotlib when you need control, and always label the axes: an unlabelled chart in a portfolio is a red flag to a hiring manager.

Interview answer

"Why NumPy instead of Python lists?" — NumPy arrays are contiguous blocks of one dtype, so operations run as compiled C loops over raw memory instead of interpreted Python loops over boxed objects. That gives 10–100× speed, far less memory, and broadcasting so I can write whole-array expressions instead of loops.

03 · Deeper

The rules under the hood

Broadcasting formally, the four kinds of indexing, missing values, merges, and what Git is actually storing.

10min

Broadcasting in one sentence

Two shapes are compatible if, comparing dimensions from the right, each pair is equal or one of them is 1; missing leading dimensions count as 1; the result takes the larger size in each position. So (64, 224, 224, 3) − (3,) works: the 3-channel mean is subtracted from every pixel of every image, which is exactly how you normalise an image batch. (3, 4) + (3,) fails because 4 ≠ 3; reshape to (3, 1) with b[:, None] and it works.

Missing values: decide, don't ignore

Titanic's age is missing for 177 of 891 rows and deck for 688. df.isna().sum() shows it. Three honest options: drop the column when mostly empty (deck); fill with a robust statistic when a minority is missing (age with the median, ideally the median per group: df.groupby("pclass")["age"].transform("median")); or flag it (df["age_missing"] = df.age.isna()) so the model can learn that missingness itself carries signal. Never fill with 0 silently: a 0-year-old is a real value with a real meaning.

Merge: joining two tables on a key

pd.merge(orders, customers, on="customer_id", how="left") keeps every order and attaches the customer's columns where the id matches, NaN where it does not. how="inner" keeps only matches; "outer" keeps everything from both. This is SQL's JOIN, and "explain left vs inner join" is asked in nearly every data interview. Always check the row count before and after a merge; an accidental many-to-many join silently multiplies rows.

Git: three areas and four commands

How to say this in an interview

Snippet 2 — load, inspect, clean

python
import pandas as pd
url = "https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv"
df = pd.read_csv(url)
df.shape, df.dtypes, df.head(), df.describe()             # the four looks you always take first
df.isna().sum()                                            # age 177, deck 688, embarked 2

df = df.drop(columns=["deck"])                              # 77% missing → drop
df["age"] = df["age"].fillna(df.groupby("pclass")["age"].transform("median"))  # fill per class
df["embarked"] = df["embarked"].fillna(df["embarked"].mode()[0])
df["family"] = df["sibsp"] + df["parch"] + 1                # new column = whole-column arithmetic
df["fare_per_head"] = df["fare"] / df["family"]
assert df.isna().sum().sum() == 0                            # prove it's clean

06 · Career corner

Data analyst is the door; ML engineer is the room behind it

3min
In job descriptions

Data Analyst, Business Analyst (Python/SQL), Junior Data Scientist, ML Engineer. The line is "Proficient in NumPy, Pandas, Matplotlib/Seaborn; comfortable with Git". Data-analyst openings outnumber ML-engineer openings roughly three to one for freshers, and the skills are a strict subset: today's loop is the entire analyst interview, and every ML engineer spends half their day doing it before any model is trained. Getting an analyst role first and moving to ML inside the company is the most common path in Indian tech, and it is a good one.

Interview questions you can now answer

  • "How would you handle missing values in a column?" — First measure how much is missing and whether it is random. Drop the column if mostly empty, fill with median (per group if there is structure) if a minority, and add a missing-flag column when missingness may carry signal.
  • "Difference between loc and iloc?" — loc selects by label (index values, column names, boolean masks); iloc selects by integer position. df.loc[df.age > 30, "fare"] vs df.iloc[0:5, 2].
  • "What is broadcasting?" — NumPy's rule for combining arrays of different shapes: align from the right, dimensions must be equal or 1, the size-1 dimension is stretched virtually. Lets me subtract a per-column mean from a whole matrix without a loop.

07 · Quiz

Three quick checks

3min

A.shape == (3, 4), B.shape == (3,). What does A + B do?

Align from the right: 4 vs 3, neither is 1, so the shapes are incompatible. Reshape B to (3, 1) with B[:, None] to add it down the columns.

df.groupby("class")["fare"].mean() returns…

Split by class, apply mean to the fare column of each group, combine into one Series whose index is the group key.

After git add file.ipynb but before git commit, the file is in the…
